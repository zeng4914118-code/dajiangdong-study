结论先行
1. 这块地不该跟江东天街、宝龙正面抢商业，它的牌是“西侧贴着公园、东边 0.44km 就是东沙湖花海”。定位为“公园边的社区生活+轻办公街区”：社区医疗与日常商业补短板，酒店和人才公寓留住人，可售部分只卖市场还买得动的小产品。
2. 25% 可售的解法：不卖大平层写字楼，卖“总价小、能自用、能出租”的东西——面积 45–90㎡ 的小办公、带公园门头的 3–4 层企业独栋、60–150㎡ 的社区街铺。先租后售、带租约销售。
3. 三个方向里我推荐 方向A「公园街区」：西低东高，独栋贴公园好卖，塔楼放东北角看湖、影子落在北侧道路上，分期最灵活。
4. 计容容积率约 3.04（73,000÷24,000），对商业/商办用地属常见区间，但需以规划条件核对用地性质、限高、退线和日照要求。推断

三、SWOT

S 优势

  • 事实西侧紧邻公园；东沙湖花海约 0.44km，处在规划东沙湖中央生态公园西缘。
  • 事实8 号线青西三路站约 1km，青六中路换乘约 1.47km。
  • 事实1.5km 内有成规模新社区：河印观翠湾 648 户、融创城 2336 户、江与锦城 1089 户等。
  • 推断方正地块、三面临路，可分期、可分栋销售。

W 劣势

  • 事实距成熟中心（江东天街约 1.6km、宝龙约 1.35km）有距离，地铁非步行即达。
  • 事实板块二手均价约 14,105 元/㎡，同比 -7.3%，市场仍在下行。
  • 推断南侧江东大道车流大、隧道口有噪声，南向恰是好朝向——朝向和噪声打架。
  • 推断办公需求薄，产权办公去化慢是钱塘普遍现象。

O 机会

  • 事实医疗短板：最近二甲市九院约 4.4km；浙大一院钱塘院区（一期 1500 床）约 3km 在建。
  • 推断院区开业后带来医护、陪护、医药配套需求，社区门诊/康复/医生公寓有落点。
  • 事实广汽整车厂约 3.2km，产业链带来商务住宿与小型办公需求。
  • 推断新社区入住率爬升中，日常型商业（超市、餐饮、儿童）存在缺口。

T 威胁

  • 推断天街、宝龙、智慧谷体量大，购物与写字楼会被虹吸。
  • 推断房价下行使投资客退场，商铺/办公“以投资为主”的老逻辑失效。
  • 推断周边若再供地同类商办，会加剧同质竞争。

建议打法：S×O——借公园和湖做“生活方式+医疗服务”的小街区；W×T——不做 Mall、不做大写字楼，体量化整为零。

五、25% 可售：难点怎么破

推断难点的根子：下行市场里没人愿意为“未来升值”买商办，所以只能卖给自用者和看得见租金的人。

产品单元买家卖点代价/风险
小面积办公45–90㎡，可合并小公司、工作室、医疗/教培个体、广汽供应链总价低、公园景观、楼下有配套产权分散后难统一运营，须在售前锁定物业与使用规约
公园企业独栋1,000–1,500㎡/栋，独立门厅+露台本地中小企业总部、诊所/医美连锁、设计机构独门独户、有门头、紧贴公园容积率低，挤压塔楼高度
社区街铺60–150㎡ 上下联铺自营商户、小投资者面向社区与公园人流不能分割过碎；业态须统一管控

销售策略 建议

  1. 先租后售：持有商业与医疗先开业，街区有人气再推可售；带租约出售（收益可见）。
  2. 分期小批量：独栋和街铺先卖（最稀缺），小办公按楼层分批推。
  3. 定向客群：联合浙大一院钱塘院区周边医疗服务商、广汽供应链企业做团购/定制。
  4. 售后统一运营：销售合同约定业态清单和统一物业，防止“卖完就空”。
  5. 留后手：小办公做成可转长租的标准层，卖不动就转持有出租。

六、对标案例（12个，全部深度）

6.1 国内深度案例（3个）。筛选口径：高层+中低层混合、临公园/景观、含办公与生活配套、非核心区、规模尽量接近5–15万㎡。坦白说：国内没有一个案例同时满足"临公园+社区医疗+酒店+可售"全部条件，以下三个各对上一部分，差距逐条写明。照片均为建筑媒体发布的项目摄影，版权归原作者，仅作内部研究。

对应判断

  • 推断"商墅"即低层可分栋的商业/办公独栋，与我们方向A的公园独栋是同一类可售产品；但英蓝商墅是否已售、售价多少，未查到公开数据。
  • 推断用古寺和庭院做低层的"前景"、塔楼退后——与我们"西低东高、独栋贴公园"的逻辑一致。

七、三个总平面方向与推荐

三个方向用同一份业态包，但可售产品的组合各有侧重。图按 160×150m 比例绘制，退线为示意（南 15m、东 10m、北 8m、西 5m），需按规划条件核准。斜线=含可售。

方向A｜公园街区（推荐）

  • 布局：西侧 3 栋 3–4F 企业独栋直接面对公园；中间 12m 南北步行街；南侧 3F 商业裙房挡住江东大道噪声；东北角 13F 办公塔看湖、东侧 13F 人才公寓；中部医疗、北部酒店。
  • 日照：高层集中在东/北，阴影主要落在北侧道路与自身后勤，不压公园与独栋。推断
  • 可售：独栋 11,880 + 街铺 3,888 + 塔楼低区小办公 2,490 = 18,258㎡（25.0%）。
  • 理由：最好卖的产品（独栋、街铺）放在最好的位置（公园、街）；持有部分集中在东侧，分期清楚：一期独栋+裙房，二期塔楼。

方向B｜退台山丘

  • 布局：南半部 2–6F 退台综合体（商业→医疗）从西向东升起，形成可走的屋顶花园；15m 东西轴连接公园与湖方向；北排公寓、酒店、东北 13F 办公塔。
  • 可售：办公塔 14,109（约 68% 楼层，小面积单元）+ 首层街铺 4,175 = 18,283㎡（24.9%）。
  • 理由：形象最强，最有“目的地”潜力（形态上参考大阪难波公园的退台花园，仅作形态参照，未列入对标）；但可售压在一栋塔楼的小办公上，去化风险最大，退台造价也最高。

方向C｜湖院

  • 布局：十字街分出四个 8–10F 周边式院落；首层全街铺，上部按院区分：西南公寓、东南办公、西北医疗+酒店、东北商业+办公。
  • 可售：东南院办公 11,606 + 东北院商办 6,636 = 18,242㎡（24.9%）。
  • 理由：街墙连续、城市感强，每院可独立分期和整院销售；但中高层围合使部分朝向和日照较差，南侧院落直面江东大道噪声，需做足退线。
